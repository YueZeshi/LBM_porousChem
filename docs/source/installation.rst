============
Installation
============


From sources
------------

The sources for LBM_poroChem can be downloaded from the `Github repo`_.

You can either clone the public repository:

.. code-block:: console

    $ git clone git://github.com/lettucecfd/

Or download the `tarball`_:

.. code-block:: console

    $ curl  -OL https://github.com/lettucecfd/lettuce/tarball/master

Once you have a copy of the source, you can install it with:

.. code-block:: console

    $ uv venv

activate the virtual environment

    $ uv pip install -e .


.. _Github repo: https://github.com/lettucecfd/lettuce
.. _tarball: https://github.com/lettucecfd/lettuce/tarball/master
